# สามดีนิยม ชามสลักชื่อ — เซิร์ฟเวอร์รับออเดอร์

ลูกค้าเปิดหน้าเว็บ → ออกแบบ (เห็นโมเดลจริง) → กด **ส่งคำสั่งทำ** → เครื่องนี้สร้างไฟล์พิมพ์ให้ทันที
(3MF แยก part ตามสี + STL + ใบสรุป) เก็บไว้ที่ `~/samdeeniyom-orders/<เลขออเดอร์>/` และแจ้งเตือนร้าน
ลูกค้า **ตรวจสถานะออเดอร์เองได้** ในหน้าเดียวกัน (เลขที่ออเดอร์ + เบอร์โทรที่ใช้สั่ง)

หน้าออกแบบไม่โหลดอะไรจากอินเทอร์เน็ต (three.js, ฟอนต์, WASM เป็นไฟล์ในเซิร์ฟเวอร์) — รายการใบอนุญาตอยู่ที่ `/licenses.html`

## ติดตั้งบน Windows
1. แตกไฟล์ zip
2. ดับเบิลคลิก **install.cmd** (ใช้ในเครื่อง: http://127.0.0.1:8787)
   หรือ **install-with-public-link.cmd** (เปิดลิงก์สาธารณะฟรีผ่าน Cloudflare ด้วย)
3. รอจนขึ้นลิงก์หน้าร้าน/หลังบ้าน และรหัสแอดมิน (บันทึกไว้ใน `%LOCALAPPDATA%\samdeeniyom-bowl\LINKS.txt` ด้วย)

ไม่ต้องใช้สิทธิ์ admin · ถ้าเครื่องไม่มี Node.js 18+ สคริปต์จะโหลดมาไว้ในโฟลเดอร์ของมันเอง
เซิร์ฟเวอร์ทำงานเบื้องหลัง (ไม่มีหน้าต่าง) และเปิดเองทุกครั้งที่ล็อกอิน Windows · หยุด/ถอนออก: **uninstall.cmd** (ไฟล์ออเดอร์ยังอยู่)
อัปเดตเวอร์ชันใหม่: แตก zip ใหม่แล้วดับเบิลคลิก install.cmd อีกครั้ง (การตั้งค่าเดิมยังอยู่)

## ติดตั้งบน Linux
```bash
./install.sh            # หรือ ./install.sh --tunnel
```

## ใช้งาน
| | ที่อยู่ |
|---|---|
| หน้าร้าน (ลูกค้า) | `/` · ใบอนุญาต `/licenses.html` |
| หลังบ้าน (ร้าน) | `/admin` — user `admin`, รหัสอยู่ใน `.env` (ADMIN_PASS) ในโฟลเดอร์โปรแกรม |
| ไฟล์ออเดอร์ | `C:\Users\<ชื่อ>\samdeeniyom-orders\<เลขออเดอร์>\` (Linux: `~/samdeeniyom-orders/`) — เปิดไฟล์ `.3mf` ในโปรแกรมสไลซ์ แล้วเลือกเส้นตามชื่อ part |

## ตั้งค่า (`.env` ในโฟลเดอร์โปรแกรม — Windows: `%LOCALAPPDATA%\samdeeniyom-bowl\.env`)
- `SDN_BED` = ขนาดพื้นพิมพ์ของร้านเป็น มม.: `256` (สี่เหลี่ยมจัตุรัส) หรือ `330x320` — ขนาดชาม/ทรงที่ใหญ่เกินพื้นพิมพ์จะปิดไม่ให้สั่งเอง (ค่าเก่า `SDN_PRINTER=a1mini|a1|sparkx_i7|current|a2l` ยังอ่านเป็นขนาดได้)
- `SDN_FREE_DOWNLOAD=1` = ให้ลูกค้าดาวน์โหลดไฟล์พิมพ์เองได้ฟรี (ค่าเริ่มต้น 0 = ร้านได้ไฟล์เท่านั้น) ถ้าเปิดหน้านี้โดยไม่มีเซิร์ฟเวอร์ ปุ่มดาวน์โหลดใช้ได้เสมอ
- `HOME_URL` = ลิงก์กลับเว็บหลัก (ไม่บังคับ)
- **หลังทันเนล/พร็อกซี:** `TRUST_PROXY=1` และ `IP_HEADER=cf-connecting-ip` (Cloudflare) — ไม่ตั้งแล้วทุกคนจะถูกมองเป็น 127.0.0.1 ตัวเดียว ตัวจำกัดจำนวนออเดอร์/การล็อกแอดมินจะนับรวมทุกคน (`install.cmd -Tunnel` ตั้งให้อัตโนมัติ) แอปควรฟังที่ `127.0.0.1` เท่านั้น
- แจ้งเตือนออเดอร์ใหม่: ใส่ `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` หรือ `DISCORD_WEBHOOK_URL` หรือ LINE OA (`LINE_CHANNEL_TOKEN` + `LINE_TO`)
- แก้แล้ว: Windows ดับเบิลคลิก install.cmd อีกครั้ง · Linux `systemctl --user restart samdeeniyom-bowl`

## ลิงก์ถาวรด้วยโดเมนของร้าน
quick tunnel จะได้ลิงก์ใหม่ทุกครั้งที่รีสตาร์ต ถ้าจะใช้โดเมนจริง (เช่น `bowl.3dniyom.com`)
สร้าง named tunnel ใน Cloudflare Zero Trust แล้วชี้ไปที่ `http://127.0.0.1:8787` (ดู `members/deploy/HOME-SERVER.md` หัวข้อชามน้องหมาน้องแมว) และตั้ง `TRUST_PROXY=1`, `IP_HEADER=cf-connecting-ip`
ถ้าจะให้การ์ดชามบนเว็บหลักชี้มาที่นี่ ใส่ที่อยู่ใน `src/hub/site.js` → `petBowlUrl`

## คำสั่งที่ใช้บ่อย
```bash
systemctl --user status samdeeniyom-bowl      # สถานะ
journalctl --user -u samdeeniyom-bowl -f      # log
grep -o 'https://[a-z0-9-]*\.trycloudflare\.com' ~/samdeeniyom-bowl/tunnel.log | tail -1   # ลิงก์สาธารณะล่าสุด
```

## ความปลอดภัย (มีเทสต์ใน `test/petbowl.test.mjs`)
- ราคาคำนวณที่เซิร์ฟเวอร์จากแค็ตตาล็อกเสมอ ราคาที่หน้าเว็บแสดงไม่ถูกเชื่อถือ · ข้อมูลที่ลูกค้ากรอกตัดอักขระควบคุมและ `<>`
- แอดมิน: ต้องล็อกอิน ผิด 10 ครั้งล็อก 15 นาที ฟอร์มเปลี่ยนสถานะตรวจ Origin (กัน CSRF) หน้าแอดมินไม่มีสคริปต์ inline
- ตรวจสถานะของลูกค้า: ต้องมีเลขที่ออเดอร์ **และ** เบอร์โทรตรงกัน ไม่ตรงตอบเหมือนกันหมด และไม่คืนข้อมูลติดต่อ
- เสิร์ฟเฉพาะไฟล์ในรายการที่อนุญาต; CSP เข้มกับหน้า (ไม่มี eval, ไม่มีบุคคลที่สาม) ผ่อนเฉพาะไฟล์ worker สร้างโมเดล
- ที่อยู่ลูกค้าเชื่อ header เฉพาะเมื่อประกาศ `TRUST_PROXY=1` (ไม่เชื่อรายการแรกของ `X-Forwarded-For`)

## ยังไม่ได้ทำ / ต้องยืนยัน
- ขนาด S และ L เป็นค่าประมาณ (ย่อ/ขยายจากถ้วยไซซ์ M) — **ต้องตรวจขนาดถ้วยสแตนเลสจริง** ก่อนรับออเดอร์ไซซ์เหล่านี้ (หน้าเว็บบอกลูกค้าว่า "ประมาณ")
- ยังไม่มีรับชำระเงินในระบบ (ร้านติดต่อกลับเอง) และยังไม่เคยพิมพ์ชามจริงจากไฟล์ที่ระบบสร้าง
- สคริปต์ติดตั้ง (`install.*`) แก้แล้วแต่ยังไม่ได้รันบนเครื่องจริง
- โค้ดชามแมวคู่ที่ถอดไปแล้วยังค้างในโค้ดวาดภาพ 3D (เข้าถึงไม่ได้จากหน้าเว็บ)
